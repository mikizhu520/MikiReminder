# MikiReminder - macOS 护眼休息提醒

一款原生 macOS 菜单栏应用，遵循 20-20-20 护眼法则，定时提醒休息、眨眼和站立，保护你的眼睛和身体健康。

## 功能特性

### 核心功能
- **20-20-20 法则**：每工作一段时间，提醒看 20 英尺（约 6 米）外的物体 20 秒
- **全屏休息界面**：深色毛玻璃风格的沉浸式休息倒计时，透出当前壁纸，舒适不刺眼
- **菜单栏计时器**：菜单栏实时显示剩余分钟数，一目了然
- **系统通知**：休息开始时发送系统通知提醒
- **推迟休息**：支持 +1 / +5 / +15 分钟推迟休息

### 健康提醒
- **眨眼提醒**：可设置间隔（1-30 分钟），屏幕中央弹出眨眼动画，提醒定时眨眼缓解眼疲劳
- **站立提醒**：可设置间隔（15-120 分钟），屏幕中央弹出站立动画，提醒站起来活动身体
- 提醒卡片 5 秒后自动消失，点击也可立即关闭

### 自定义设置
- **可调时长**：工作时长 5-60 分钟，休息时长 10-300 秒
- **快速预设**：20-20-20（标准护眼）、25-5（番茄工作法）、50-10（深度工作）
- **严格模式**：开启后休息期间无法跳过，必须完成
- **提示音**：休息开始/结束播放系统音效
- **开机自启动**：登录时自动启动
- **菜单栏倒计时**：可开关菜单栏时间显示
- **空闲时暂停**：检测到电脑空闲时自动暂停计时

### 界面设计
- **毛玻璃下拉面板**：半透明毛玻璃效果，清晰透出桌面
- **纯黑倒计时**：大字号加粗黑色数字，清晰醒目
- **长休息 / 短休息**：休息时长 ≥ 60 秒自动识别为长休息，显示对应安慰文案
- **右键菜单**：立即休息、推迟休息、暂停/继续、停止、设置、关于、退出

## 系统要求
- macOS 12.0 (Monterey) 或更高版本
- Xcode Command Line Tools（仅编译时需要，`xcode-select --install`）

## 安装与运行

### 编译安装

```bash
git clone https://github.com/yourname/MikiReminder.git
cd MikiReminder
chmod +x build.sh
./build.sh
```

构建完成后，应用位于 `build/MikiReminder.app`，双击即可运行。

安装到应用程序目录：

```bash
cp -R build/MikiReminder.app /Applications/
```

## 使用说明

1. 启动后，应用出现在菜单栏（眼睛图标 + 分钟数）
2. 点击菜单栏图标打开下拉面板，查看倒计时、立即休息、推迟休息
3. 休息时间到时，显示全屏毛玻璃休息界面，倒计时结束自动返回工作
4. 右键菜单栏图标打开更多操作菜单
5. 点击齿轮图标进入设置，自定义时长、提醒间隔、严格模式等

## 技术栈

- **Swift**：开发语言
- **SwiftUI**：声明式 UI 界面
- **AppKit**：菜单栏、窗口管理、毛玻璃效果、系统通知
- **Combine**：响应式数据绑定（`ObservableObject` / `@Published`）
- **UserNotifications**：系统通知
- **UserDefaults**：设置持久化
- **swiftc**：命令行编译，无 Xcode 项目依赖

## 隐私说明

- 所有设置仅存储在本地 UserDefaults
- 不收集任何用户信息，不联网，不上传数据
- 眨眼/站立提醒仅在本地计时触发
